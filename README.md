
# SCT_DA_1

## Overview
Developed an interactive Business Performance Dashboard in Excel to analyze sales trends, customer segments, regional performance, and year-over-year growth.

## Features
- KPI Cards
- Sales by Category
- Segment-wise Analysis
- Region-wise Performance
- Top 5 States by Sales
- YOY Sales Growth Trend

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## Key Insights
- Consumer segment generated highest sales contribution.
- California achieved maximum sales.
- Technology category outperformed other categories.
- Strong YOY growth observed in 2018.
